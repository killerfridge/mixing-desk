# Publication audit — 2026-10-04

- GitHub repository metadata confirmed `killerfridge/mixing-desk` is already public. Default branch: main. Existing history was preserved; no visibility change was made.
- The reachable history and current working source were scanned for private keys, common GitHub/AWS credentials, long credential assignments, and signing material using `scripts/audit-source.py`. No matches were found. This pattern scan is not proof that every possible secret is absent.
- Git history contains contributor email metadata, including the original personal author address. It was already publicly reachable. This audit does not reproduce those addresses or rewrite history. Release-preparation commits use the maintainer’s GitHub noreply address.
- Application, engine, driver, build manifests, and dependencies were reviewed for network clients, telemetry, audio-file recording, and uploads. No app-owned implementation was found. Third-party plugin behaviour is outside that statement; see PRIVACY.md.
- All 65 vendored files under `Sources/DeskAudio/VST3SDK/pluginterfaces` were byte-compared against Steinberg’s source archive at commit `4f547e8e102b47de4a8b8aaf343c73b700786372`; every file matched, including its MIT licence. The archive was inspected in memory and no source from it was executed.
- The app ships Steinberg’s notice and the project MIT licence. No BlackHole source/binary, vendor plugins, plugin licences, private sessions, or audio recordings are included in the payloads.
- The icon is original vector artwork generated by the checked-in AppKit script. Documentation images render actual app views using an isolated unassigned session; no personal session, real device IDs, or audio capture was used.
- Audit must be repeated for the final release tag. Clean-Mac installation, independent users, and real hardware acceptance remain separate publication gates.
