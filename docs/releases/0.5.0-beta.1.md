# Mixing Desk 0.5.0-beta.1

Experimental beta candidate for Apple Silicon and macOS 14.4+. This document is release preparation, not evidence that acceptance checks have passed.

## Changes

- Combined graphical installer with an optional, initially unchecked virtual-audio driver; separate driver-removal package.
- Hardware-neutral setup guide and three unassigned starter sources, retaining call-return exclusion.
- Read-only driver readiness and restart/update guidance.
- App icon, illustrated quick start, MIT licence, privacy notes, and release automation.

App version: 0.5.0, build 10. Driver: 0.1.1, build 2; protocol and device identities are unchanged. Existing version-1 sessions are preserved. An existing compatible driver does not need reinstalling for this app update.

## Before installing

These builds are ad-hoc signed and unnotarized; the packages are unsigned. Read INSTALL.md and Apple’s manual-approval guidance. Updates may require renewed privacy approval. Managed Macs may block installation. Quit the app before replacement. Selecting the driver component or using the removal package requires a restart.

## Known limitations

- Apple Silicon only; engine fixed at 48 kHz.
- VST3 uses generic parameter editors, not vendor windows or vendor preset browsers. AUv2 can use native editors.
- No parallel-path delay compensation; displayed latency is an estimate, not measured round-trip latency.
- Clipping indicators, no limiter. Start monitoring at a low level.
- Active plugins and AU discovery execute in-process and may crash or hang the mixer. VST3 discovery is isolated; DSP is not.
- Plugin buses cannot feed other buses; missing/failed active plugins silence wet output until explicitly bypassed.
- AUv3, VST2, instruments, external MIDI, sidechains, and transport automation are not supported.
- Clean-Mac installation, macOS 14.4/current-OS coverage, multi-interface friend testing, and real 60-minute audio acceptance must be recorded before public binaries are published.

Support is best effort through GitHub Issues. Include exact versions and reproduction steps; review logs and sessions before sharing them.
